# SDN150S Inventory System

## Features
* *Login:* Secure access (devcore / dev2026).
* *Dashboard:* Automatically calculates Total Items, Quantity, and Value.
* *Manage Items:* Add, Update, and Remove stock.
* *Tracking:* Tracks item locations and low stock alerts.
* *Search:* Easily find items in the table.
* *Reports:* Generates a system summary.
  
## How to Run
1. Open the project in NetBeans.
2. Run LoginPage.java.
3. Use *devcore* as username and *dev2026* as password.
